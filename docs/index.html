India Post Dashboard

India Post Dashboard is an internal web application for the Circle Office, Haryana, India Post. Its purpose is to help authorized staff manage the office's day-to-day operations: track records and submissions, assign and approve tasks, generate reports, send notifications, and maintain a complete audit log of actions.

Official organizational use Google Workspace application © 2026 Circle Office, Haryana

What the application does

India Post Dashboard turns a Google Spreadsheet maintained by the Circle Office, Haryana into a live, role-based operations dashboard for authorized India Post personnel. It is used to:

  • Manage operational records and status tracking across the circle
  • Track submissions, tasks, approvals, and workflows
  • Generate operational reports and analytics
  • Maintain an audit log of user actions for accountability

Who can use it

The application is intended exclusively for authorized staff of the Circle Office, Haryana, India Post. Access is controlled by role-based login and permission groups. It is not offered to the general public and does not display advertising.

Google services used

The application is built on Google Workspace and uses the minimum Google services required to function:

Google Sheets

Reads and writes records in the organization-owned dashboard spreadsheet (records, submissions, tasks, approvals, audit log).

Google Drive

Stores documents attached to records and temporary report and export files. Only files created or opened by the application are accessed.

Identity

Uses the user's email address to identify the signed-in user, apply role-based permissions, and record an audit trail of actions.

No user data is sold, rented, or shared for advertising. Full details are described in the Privacy Policy.

Access the Dashboard

The dashboard is embedded below. It is built on Google Apps Script and connects to your organization's Google Sheets data.

The embedded dashboard loads from a Cloudflare Worker reverse proxy (app.dashboardharyana.site) that serves the Google Apps Script web app from your own domain and strips the Google disclaimer banner. If the proxy is not yet deployed, the dashboard will fall back to loading directly from script.google.com.
