India Post Dashboard

The official internal operations dashboard of the Circle Office, Haryana, India Post. It provides authorized staff with role-based access, operational reporting, workflow management, user administration, and audit logging.

Official organizational use Google Workspace application © 2026 Circle Office, Haryana

Purpose of the application

The India Post Dashboard is an internal web application built for the Circle Office, Haryana, India Post. Its purpose is to help authorized officials track and manage the office's day-to-day operations by turning a Google Spreadsheet into a live operations dashboard with:

  • Role-based login and access control for authorized staff
  • Record management and status tracking across the circle
  • Workflow management, task assignments, and approvals
  • Reporting, analytics, and audit logging for accountability

The application is intended exclusively for official use by authorized India Post personnel. It is not offered to the general public and does not display advertising.

About the application

India Post Dashboard turns a Google Spreadsheet maintained by the Circle Office, Haryana into a live, role-based operations dashboard for authorized personnel.

Access is restricted to authorized users. The application uses the minimum Google account information and Google Workspace services required to function:

Authentication & identity

Uses the user's email address to identify the signed-in user, apply role-based permissions, and record an audit trail of actions.

Google Sheets

Reads and writes records in the organization-owned dashboard spreadsheet (e.g., records, submissions, tasks, approvals, audit log).

Google Drive

Stores documents attached to records and temporary report/export files. Only files created or opened by the application are accessed.

Email

Sends transactional email to users, such as password-reset links and scheduled report deliveries.

No user data is sold, rented, or shared for advertising. Full details are described in the Privacy Policy.
