# Admin Guide

## Admin user

- `vcharyanaco@gmail.com` is configured as the admin user.
- Admins can create, update, and delete records.
- Other users will see read-only dashboard content.

## Application settings

- Navigate to the `Settings` tab.
- Update app title, sheet name, and data start row.
- Save changes and refresh the app.

## Audit log

- The `Audit Log` tab shows the last 80 entries.
- Actions such as ADD, UPDATE, DELETE, and ERROR are tracked.
